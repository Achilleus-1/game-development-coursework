# Game Development Coursework

Unity C# gameplay scripts for a procedural grid, a trench-run obstacle game, and a ghost/treasure prototype.

## Original coursework

- CS 4423-01T — Game Development, Summer 2025

Originally completed at the University of Texas at San Antonio during the terms above and imported to GitHub later. This repository preserves the submitted implementation; repository documentation and import housekeeping were added separately.

**Languages and technologies:** C#, Unity, Unity Input System.

## Implementation

- Procedural grid/house placement.
- Player movement, camera tracking, obstacles, and obstacle spawning in a trench-run prototype.
- A first-person treasure prototype with ghost behavior and sound following.

## Concepts

- Component-based gameplay, input handling, collision responses, spawning, cameras, and simple enemy behavior.

## Running the source

These submissions contain scripts only. Import a prototype directory into a compatible Unity project and supply its scenes, prefabs, references, and input bindings. GameInputActions.cs is a required generated Input System source binding retained from the original submission.

## Scope and limitations

- Scenes, asset packs, audio, screenshots, and builds are excluded; these are not complete runnable Unity project exports.
- Required generated C# input bindings are identified rather than counted as wholly handwritten code.

Only source code, build configuration, and required text inputs are included. Written submissions, assignment instructions, PDFs, videos, generated outputs, binary builds, and private configuration are omitted. Anonymized contributor labels and supplied-code comments retain the distinction between submitted work and scaffolding. No license for course-provided material is inferred.
